# ♟️ Real-Time Multiplayer Chess Game

A real-time multiplayer Chess Game built using **Node.js**, **Express.js**, **Socket.IO**, and **Chess.js**. Two players can join the game as White and Black, while additional users can watch as spectators. The game validates all moves and synchronizes the board in real time.

---

## 🚀 Live Demo

🔗https://chess-g2f6.onrender.com

## ✨ Features

- ♟️ Real-time multiplayer gameplay
- 🌐 Socket.IO based communication
- ✅ Legal move validation using Chess.js
- 👥 Automatic White & Black player assignment
- 👀 Spectator Mode
- 🔄 Live board synchronization
- 🎯 Drag & Drop chess pieces
- 📱 Responsive UI

## ⚙️ Installation

Clone the repository
```bash
git clone https://github.com/PushkarArya01/chess.git
```
Move into the project
```bash
cd chess
```
Install dependencies
```bash
npm install
```
Start the server
```bash
npm start
```
Open your browser
```
http://localhost:3000
```

## 🎮 How to Play

1. Open the application in two browser windows.
2. The first player joins as **White**.
3. The second player joins as **Black**.
4. Any additional users become **Spectators**.
5. Drag and drop pieces to make moves.
6. All moves are validated by Chess.js.
7. The board updates instantly for every connected player.
